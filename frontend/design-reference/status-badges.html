Статус-бейджи и индикаторы

Демонстрация pill-бейджей для статусов заявок в myCRM (ERP монтажных работ). Три визуальных варианта одного и того же набора статусов — default, subtle, outline — плюс легенда соответствия статус → цвет.

Вариант «default» — заливка насыщенным цветом

В ожидании Принят Выполнено Архив

Вариант «subtle» — заливка + рамка в тон (по умолчанию в таблицах/карточках заявок)

В ожидании Принят Выполнено Архив

Вариант «outline» — только рамка, без заливки

В ожидании Принят Выполнено Архив

Легенда статусов

Соответствие статуса заявки семантическому цвету и токену. Статусы 1–3 приходят из поля заявки, «Архив» — отдельный флаг для скрытых/архивных заявок.

Код Статус Цвет Пример Токен
1 В ожидании Жёлтый (warning) В ожидании --c-warning
2 Принят Голубой (info) Принят --c-info
3 Выполнено Зелёный (success) Выполнено --c-success
— Архив Серый (neutral) Архив --c-neutral
